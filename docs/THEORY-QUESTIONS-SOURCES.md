## 1. Primary Archival Sources

Every theory question and marking scheme in this catalog originates from official examination archives. No synthetic or artificial questions are admitted.

## 2. Reliability and Verification Standards

The integrity of theory marking keys requires strict accuracy. We apply four verification checks to every question payload before database insertion:

### A. Mathematical and Dimensional Soundness
Every mathematical step is recomputed independently. Where multiple legitimate paths exist, each path is recorded as an alternative method:
* For quadratic formulations, roots are verified against original boundary conditions ($2(L + B) = 48$ and $L \times B = 135$).
* For mechanics problems, values are confirmed using both kinematic formulas and energy conservation principles ($v_y^2 = u_y^2 - 2gh$ and $\frac{1}{2}m u_y^2 = mgh$).
* SI units and significant figures are verified against international standards and WAEC rounding rules.

### B. Authentic WAEC Marking Logic ($M$, $A$, and $B$ Marks)
Mark designations are preserved exactly as defined by WAEC subject panels:
* **Method Marks ($M$)**: Allocated for correct mathematical formulation or process. A candidate must show recognizable substitutions.
* **Accuracy Marks ($A$)**: Dependent on the preceding method mark ($M0 \implies A0$). If a candidate uses an erroneous formula, all subsequent accuracy marks within that sub-part are lost.
* **Independent Marks ($B$)**: Awarded for standalone statements, definitions, or correct diagram annotations regardless of method.

### C. Examiner Penalties Protocol
Official deduction penalties enforce genuine exam-room grading standards:
* **Unit Omission**: Deducts 1 mark from the final step mark if standard SI units are missing or incorrect.
* **Premature Rounding**: Deducts 1 mark if intermediate calculations are rounded too early, producing an inaccurate final result.
* **Summary Lifting Penalty**: In English summary writing, copying a sentence word for word from the passage results in zero marks for that point.
* **Incomplete Sentences**: Deducts 1 mark for thoughts expressed as fragments rather than complete grammatical sentences.

### D. Chief Examiners' Commentary
Examiner reports are transcribed directly from official annual review volumes. They highlight:
* Specific algebraic errors observed across thousands of student scripts.
* Confusions between horizontal and vertical velocity components.
* Actionable remedies recommended by chief examiners to improve classroom preparation.

## 3. Storage and Repository Hygiene

To safeguard copyrighted past paper materials and prevent repository bloat:
* All raw JSON source documents remain gitignored in `data/theory/`.
* Imported records are synchronized directly into the live production Turso cloud database.
* Data access occurs exclusively through typed API endpoints (`/api/v1/theory/*`) under API key authentication and rate limiting.
